# Pruebas

Acá van las pruebas: no son infografías para publicar, no entran en la galería del README y los scripts no las usan.

- `jugadores_nuevos/`: pruebas con partidos ya jugados de los jugadores agregados el 21/10/2026 (J. M. Giménez, Amaro, R. Araújo, Sanabria, Canobbio, Darwin Núñez, Torreira y F. Díaz). Se armaron con el diseño actual solo para ver que el script los encuentra; no se marcaron como procesadas.
- `bocetos_diseno/`: propuestas de un diseño nuevo para la parte de abajo (SU PARTIDO, TOTALES, mapa y temporada), con datos reales de Mouriño (Liverpool 4-3 Villarreal, 20/10) y Zalazar (Sporting 2-2 Arouca, 19/09). Todavía no se decidió; `render_v3.py` no cambió. En `codigo/` están los scripts y los datos con los que se armaron.
- `viejas/`: pruebas anteriores que estaban mezcladas con las infografías: la de Mouriño vs. Betis del 14/09 (formato viejo, de prueba), los mapas de calor de esa prueba y de una de Bernal del 17/09 que nunca tuvo infografía, y dos figuras de ejemplo que no usa ningún script.
